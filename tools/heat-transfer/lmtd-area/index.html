この計算で扱う範囲

定常状態で、高温側から低温側へ熱が移るモデルです。流量・比熱・総括伝熱係数の変化が小さく、外部への熱損失を無視できる条件を想定します。相変化がある場合は、等温で変化する区間として分けて扱います。

4つの温度だけでは、両流体の熱収支が一致しているかは確認できません。Q は物質・熱収支から求めた値を使います。

数式と確認できること

ΔTlm = (ΔT₁ − ΔT₂) / ln(ΔT₁ / ΔT₂)
A = Q / (U · F · ΔTlm)

両端の温度差が同じときは ΔTlm = ΔT₁ = ΔT₂。温度差が近い場合も、直接の割り算による桁落ちを抑えます。どちらかの温度差が 0 以下の場合は、正の有限な面積として表示しません。

向流：ΔT₁ = Th,in − Tc,out、ΔT₂ = Th,out − Tc,in
並流：ΔT₁ = Th,in − Tc,in、ΔT₂ = Th,out − Tc,out

単純な向流・並流では F = 1。多パスなどでは向流基準の LMTD に、装置条件に対応する F を掛けます。F を入力しても装置配置の実現可能性まで確定するものではありません。
